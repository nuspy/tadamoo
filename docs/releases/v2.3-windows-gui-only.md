# TaDaMoo GUI only for Windows, 2.3 (victory-lap)

Only the desktop window, no engine, no Python, no local server: at its first start it asks which TaDaMoo server to use.

- **File:** `TaDaMoo-Windows-GUI-only-v2.3.zip` (67 MB).
- **SHA-256:** `b789aeb4595dbd4d417fc5ed2f716b3fe05007a507f67523d380154ae7ffff6b`
- **Needs:** Windows 10 or 11 x64 and the WebView2 runtime.
- **Install:** unzip, right-click `Install-TaDaMooGUI.ps1` > Run with PowerShell (administrator rights). `Remove-TaDaMooGUI.ps1` removes it.

## New in 2.3 (victory-lap)

The app itself is unchanged since 2.2; it is published again so that all five packages carry the same number. What changed is in the server and the engine: see the notes of the Windows and Linux packages.
