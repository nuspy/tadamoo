# TaDaMoo for Windows, 2.1 (statutory-gravity)

The full setup: the Basalt-Plus engine, the harness (server and web page), the desktop app, agent-desktop and agent-browser, and everything they need on one PC.

- **File:** `TaDaMoo-Windows-v2.1-setup.exe` (704 MB).
- **SHA-256:** `0a07b10cb64cc7eb4909bb7c7fcb40be6d37308cef32f779323c88eb4e8cda7d`
- **Needs:** Windows 10 or 11 x64. For the engine, an NVIDIA Blackwell GPU (RTX 50 series) and its driver; without it the harness runs through the providers.
- **Install:** run the setup, then `TaDaMoo.exe`. agent-desktop is not signed: SmartScreen or an antivirus may warn, and the built-in backend is the fallback.

## New in 2.1 (statutory-gravity)

- **The register of work**: a Tasks tab with the open tasks of every project as a tree, a spine view and a history of the closed ones, groups, hide and delete, and the conversation's own tasks in the Chat. A task carries its git branch and commits, shown as links to the project's remote. `docs/roadmap.json` is written from the register and read back.
- **Voice in the Chat and in Agentic coding**: talk, hear the answers, hands-free conversation; push-to-talk; the agent knows the voice and has tools for it. The speaker is recognised by voice, live on a call or with push-to-talk, enrolled only with the owner present.
- **Settings > Voice/Avatar** in six sub-tabs, a real voice list per language with a preview, and a Voice tab for trying and live use only. Telephony has its own section. Models > Voice services says what Apply does and shows *When* for the three services.
- **Contacts**: a top-level tab with groups, contacts, permission types and categories; a phone call carries who the number belongs to and what is granted.
- **Summaries in four levels** (integral, medium, high, executive) with a panel in Settings > Inference; a grammar check with a model per language after a translation.
- **Export**: a Markdown file is saved as it is, converted, or both; documents are read as Markdown with MarkItDown.
- **Chat folders and sessions**: separate base folders for Chat and Agentic coding, rename from the keyboard or a right click, a message not yet confirmed survives a server restart.
- **Updates**: one window for Imported, Skills and Connectors, with three versions of each file and a choice per conflict; a plugin brings its own program and loads it on first use.
- **The engine (Basalt-Plus)**: a LoRA adapter is fused into the dense matrices at load (`--lora`, `--lora-scaled`), with a converter from PEFT adapters; the IQ4_NL, IQ4_XS, IQ2_S, IQ3_XXS and IQ3_S quantizers; the start waits for a load that still reports progress.
- **Desktop**: *Turn off* in the tray brings the question to the front, asks once and no longer freezes the window; `Ferma-TaDaMoo.ps1` also stops the Windows service that keeps the server up.
