# TaDaMoo for Android, 2.5 (victory-lap)

The phone app: chat, voice, avatars, the Actions tab with a read-only Tasks part, and the connection to your server by name (`http://` or `https://`).

- **File:** `TaDaMoo-android-v2.5.apk` (165 MB).
- **SHA-256:** `4f4d556df437fe4c1d9244d301c9bf5b152ee42c3a645f4c7e0a3b2228c37520`
- **Install:** allow installs from this source, open the file; allow notifications at the first start.

## New in 2.5 (victory-lap)

The app is unchanged since 2.4 and is published again so that all five packages carry the same number. The settings page of the chat opens the inference settings, which now include the "Words per token (%)" field. The server must be 2.5 too to use it.
