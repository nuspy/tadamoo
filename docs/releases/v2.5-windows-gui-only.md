# TaDaMoo GUI only for Windows, 2.5 (victory-lap)

Only the desktop window, no engine, no Python, no local server: at its first start it asks which TaDaMoo server to use.

- **File:** `TaDaMoo-Windows-GUI-only-v2.5.zip` (69 MB).
- **SHA-256:** `09e6709755fb76892faeb051eeca03fb187eeba471c99a3f921dbcad42271670`
- **Needs:** Windows 10 or 11 x64 and the WebView2 runtime.
- **Install:** unzip, right-click `Install-TaDaMooGUI.ps1` > Run with PowerShell (administrator rights). `Remove-TaDaMooGUI.ps1` removes it.

## New in 2.5 (victory-lap)

The desktop window is unchanged since 2.4 except for the new "Words per token (%)" field of the inference settings; it is published again so that all five packages carry the same number. The rest of what changed is in the server it connects to: see the notes of the Windows and Linux packages.
