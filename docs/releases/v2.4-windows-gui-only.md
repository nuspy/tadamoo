# TaDaMoo GUI only for Windows, 2.4 (victory-lap)

Only the desktop window, no engine, no Python, no local server: at its first start it asks which TaDaMoo server to use.

- **File:** `TaDaMoo-Windows-GUI-only-v2.4.zip` (69 MB).
- **SHA-256:** `909a6e4cffd8c997d89b704073ae5f69b9fc7dbd3b1ab35114e166da8b9956cc`
- **Needs:** Windows 10 or 11 x64 and the WebView2 runtime.
- **Install:** unzip, right-click `Install-TaDaMooGUI.ps1` > Run with PowerShell (administrator rights). `Remove-TaDaMooGUI.ps1` removes it.

## New in 2.4 (victory-lap)

The desktop window is unchanged since 2.3; it is published again so that all five packages carry the same number. What changed is in the server it connects to (the order of the providers, the context, the long answers): see the notes of the Windows and Linux packages.
