# TaDaMoo GUI only for Windows, 1.12

Only the desktop window, no engine, no Python, no local server. At its first start it asks which TaDaMoo server to use: a Linux install behind nginx, or any server that already runs.

- **File:** `TaDaMoo-Windows-GUI-only-v1.12.zip` (69 MB).
- **SHA-256:** `28ac20e79228f0f061e6019c9f265b3bd53becb00bc2f5dec05a7381a18f3230`
- **Needs:** Windows 10 or 11 x64 and the WebView2 runtime (part of Windows 11; without it the app opens the page in the browser).
- **Install:** unzip, right-click `Install-TaDaMooGUI.ps1` > Run with PowerShell (it asks for administrator rights). It copies the folder to `C:\Program Files\Tadamoo\TaDaMooGUI` and adds a Start menu shortcut and an Installed apps entry. `Remove-TaDaMooGUI.ps1` removes it and leaves your list of servers.
- **Servers:** each entry has a name, an `http://` or `https://` address, and a key you can edit. The key is stored per user, protected with DPAPI. See `docs/desktop-servers.md` and `docs/windows-gui-only.md`.
