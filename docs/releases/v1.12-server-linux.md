# TaDaMoo server for Linux, 1.12

The repository tree with the installer, for a Linux server. The interface on Linux is the web page the harness serves; the desktop apps and the Android app connect to it.

- **File:** `TaDaMoo-server-linux-v1.12.tar.gz` (15 MB).
- **SHA-256:** `01862e2d2de77bb12d1b398f7983d5bd8e01477f54430676577ef79442997cf7`
- **Needs:** Linux with systemd, Python 3.10 or newer with `venv` and `pip`. An engine needs an NVIDIA GPU (Basalt-Plus: Blackwell).

```
tar xzf TaDaMoo-server-linux-v1.12.tar.gz && cd tadamoo-1.12
sudo deploy/linux/install.sh install --public-name tadamoo.example.org --proxy nginx --generate-key
```

Three components in one installation: the harness (always), the Basalt-Plus engine and the Strata engine (only when asked: `--components harness,basalt --engine-bin /path/to/basalt`). The engines' binaries are not in this file. `--no-web` serves only the API. `--proxy nginx|caddy|npm` writes a ready recipe for a proxy in front.

Docker files and a Helm chart for Kubernetes and k3s (an NVIDIA GPU already set up in the cluster) are in `deploy/`. See `docs/deploy.md`.

## Checked

The harness install was run on Ubuntu 24.04 behind Nginx Proxy Manager: the service starts, the key is required, the key changes remotely and applies at once. The engines, the Docker images and the Helm chart on a real cluster were not run.
