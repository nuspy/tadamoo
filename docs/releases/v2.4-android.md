# TaDaMoo for Android, 2.4 (victory-lap)

The phone app: chat, voice, avatars, the Actions tab with a read-only Tasks part, and the connection to your server by name (`http://` or `https://`).

- **File:** `TaDaMoo-android-v2.4.apk` (165 MB).
- **SHA-256:** `67c1e72f2777b52336a0ffc19398c5f442df395d25e941e02bac9dfd0f491372`
- **Install:** allow installs from this source, open the file; allow notifications at the first start.

## New in 2.4 (victory-lap)

The gear icon of the chat opens the inference settings again: the app puts the key in a cookie and the listener for phones reads it for the page and its own files only, so the error "missing or wrong API key" is gone. The server must be 2.4 too. The rest of the app is unchanged since 2.3.
