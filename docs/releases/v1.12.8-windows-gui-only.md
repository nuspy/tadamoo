# TaDaMoo GUI only for Windows, 1.12.8 (bizarre-smarttv)

Only the desktop window, no engine, no Python, no local server: at its first start it asks which TaDaMoo server to use.

- **File:** `TaDaMoo-Windows-GUI-only-v1.12.8.zip` (73 MB).
- **SHA-256:** `d9958705e5be4d4c9fd71113edfd1cd70b3fe2bd19502b73c61303a0ecec00f0`
- **Needs:** Windows 10 or 11 x64 and the WebView2 runtime.
- **Install:** unzip, right-click `Install-TaDaMooGUI.ps1` > Run with PowerShell (administrator rights). `Remove-TaDaMooGUI.ps1` removes it.

## New in 1.12.8 (bizarre-smarttv)

- **Computer control**, on by default: mouse, keyboard, screenshots and the accessibility tree of any window, with a stop at once when you move the mouse to a corner. It uses **agent-desktop** (Vercel Labs, Apache-2.0, built from `third_party/` and shipped inside), which reads the accessibility tree of Windows, Linux and macOS and acts on elements without moving your mouse; the built-in backend is the fallback.
- **Browser**: one selector, *agent-browser* (Vercel Labs, Apache-2.0, built from `third_party/` and shipped inside; the default) or TaDaMoo's own driver, for everything, vault and payments included. agent-browser is not yet at parity with the own driver: `docs/browser-backends.md` lists what differs.
- **Administering a server from the page or the app**: `--remote-admin` (off unless asked, needs a key) lets a client with the key do what only the server's PC could do. The key is kept in the browser between visits, with a *Forget key* button, and the *Models* tab stays on a server with no engine.
- **Fixes**: the knowledge archives' news call (`/api/attention`) failed on every installation; the RAG drivers (PostgreSQL and the SQLite vector extension) are now installed with the program.
- **Licence**: the README and `CONTRIBUTING.md` state the licence of the code (`LICENSE`).
