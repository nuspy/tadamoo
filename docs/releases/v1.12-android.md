# TaDaMoo for Android, 1.12

The phone app: chat, voice, the Required actions tab with standard notifications (one per new item), and the connection to your TaDaMoo server.

- **File:** `TaDaMoo-android-v1.12.apk` (164 MB).
- **SHA-256:** `e82e9f7ad3c853c4d9cb9f03b90af47200a421b77426b42741389c1e2605d8d4`
- **Install:** allow installs from this source, open the file. Allow notifications at the first start.
- **Server:** the address accepts `http://name[:port]`, `https://name[:port]` or `name[:port]` (also a Tailscale IP address). The key is editable, and "Change the key on the server" changes it on the server and keeps it on the phone.
