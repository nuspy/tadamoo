# TaDaMoo for Android, 2.1 (statutory-gravity)

The phone app: chat, voice, avatars, the Actions tab with a read-only Tasks part, and the connection to your server by name (`http://` or `https://`).

- **File:** `TaDaMoo-android-v2.1.apk` (165 MB).
- **SHA-256:** `8b6c8a1c6943e5e177147838c28a616d786e1eadaf5f82a922d81d186dafb506`
- **Install:** allow installs from this source, open the file; allow notifications at the first start.

## New in 2.1 (statutory-gravity)

- **Tasks**: the Actions tab has a third, read-only part with the open tasks of every project, their state, what is done and what is missing, and the branch and commits that open the remote's page.
- **While the agent works**: messages can be sent, the answer shows pictures and charts, and a long answer is offered in full.
- **Inference settings**: the same page as on the web and the PC, opened in the app.
- **Voice, contacts and summaries** come from the server: see the Windows notes of this release.
