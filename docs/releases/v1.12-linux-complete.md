# TaDaMoo for Linux, complete, 1.12

The harness (server and web page), the installer and the Basalt-Plus engine built for Linux x86_64 with the CUDA 13 runtime libraries it needs, in one archive. The interface on Linux is the web page the harness serves; the desktop apps and the Android app connect to it.

- **File:** `TaDaMoo-linux-complete-v1.12.tar.gz` (457 MB).
- **SHA-256:** see `SHA256SUMS.txt` in this release.
- **Needs:** Linux x86_64 with systemd, Python 3.10 or newer with `venv` and `pip`. The Basalt-Plus engine needs an NVIDIA Blackwell GPU (RTX 50 series, compute capability 12.0) and its driver.

```
tar xzf TaDaMoo-linux-complete-v1.12.tar.gz && cd tadamoo-1.12
sudo deploy/linux/install.sh install --components harness,basalt --public-name tadamoo.example.org --proxy nginx --generate-key
```

- **harness** is always installed; the engine is found in `engines/basalt` of this archive (`--engine-bin FILE` takes another binary).
- **Strata** (other GPU families, other models) is another project and is not in this file: `--components harness,strata --strata-variant cuda13` fetches its engine from its own release (cuda13, cuda12, hip-halo, hip-rx6000, hip-rx7900, hip-rx9070) and checks it against its `SHA256SUMS.txt`.
- `--no-web` serves only the API. `--proxy nginx|caddy|npm` writes a ready recipe for a proxy in front. The key can be changed later from the page, from the desktop app and from a connected client.
- Docker files and a Helm chart for Kubernetes and k3s are in `deploy/`. See `docs/deploy.md`.

## Checked

The engine was built by the repository's workflow on Ubuntu 24.04 with CUDA 13.0 (`.github/workflows/engine-linux.yml`), and its libraries resolve from the archive on a clean Ubuntu. It was not run on a GPU here. The harness install was run on Ubuntu 24.04 behind Nginx Proxy Manager. The Strata download was checked up to its release lookup.
