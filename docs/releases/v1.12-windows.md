# TaDaMoo for Windows, 1.12 (bizarre-smarttv)

The full setup: the Basalt-Plus engine, the harness (server and web page), the desktop app and everything they need on one PC.

- **File:** `TaDaMoo-Windows-v1.12-setup.exe` (574 MB).
- **SHA-256:** `148dd8418afac1923746fe6311326fbe9a173a469c38a62eb76728851c09dcf3`
- **Needs:** Windows 10 or 11 x64. For the engine, an NVIDIA Blackwell GPU (RTX 50 series) and its driver. Without it the harness still runs through the providers (cloud or an engine elsewhere).
- **Install:** run the setup. It puts the program in `C:\Program Files\Tadamoo\TaDaMoo`, installs Python and the packages from the bundled files if the PC has none, and adds a shortcut. Start `TaDaMoo.exe`.

## What is new

- The desktop app connects to a **remote server**: a list of servers (name, `http://` or `https://` address, key), a "This PC" entry and a Test button. See `docs/desktop-servers.md`.
- **Settings > Network**: listening address and port, allowed names, public name, and a Test button that goes through a proxy.
- The **server key** can be changed from the page, from the app and from a connected client, and applies at once.
- **Required actions**: one list of what waits for you (permission questions, plan tasks and decisions), with buttons, in the page and as a tray balloon.
- Newscast production: interlude, filler footage by place, resident models, an evidence card, a plan that runs by itself.
